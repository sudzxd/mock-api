## [0.1.0] - 2026-01-08

### Added

- Initial release
- Pydantic model parser with automatic field type detection
- Mock data generator using Faker for realistic test data
- In-memory CRUD store with foreign key relationship support
- FastAPI route generator with automatic REST endpoint creation
- CLI commands: serve, generate, validate
- Comprehensive test suite (167 tests, 90%+ coverage)
- Development tooling: Makefile, ruff, pyright, pytest
